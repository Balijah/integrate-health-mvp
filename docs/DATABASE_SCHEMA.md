# Database Schema

This is a readable overview of the current PostgreSQL schema. Alembic migrations under `backend/alembic/versions/` are the source of truth for deployed schema changes; SQLAlchemy models under `backend/app/models/` are the source of truth for application mappings.

Current migration head: `008_add_audit_log`.

## Relationships

```text
users 1 ---- * visits 1 ---- * notes
                    |
                    +------ * transcription_sessions

audit_logs records security-relevant events without a database foreign key
```

Deleting a user cascades to visits. Deleting a visit cascades to its notes and transcription sessions. A visit's pointer to its current transcription session is set to null if that session is removed.

## Tables

### `users`

Provider accounts.

| Column | Type | Notes |
| --- | --- | --- |
| `id` | UUID | Primary key |
| `email` | varchar(255) | Unique, indexed |
| `hashed_password` | varchar(255) | Never contains plaintext |
| `full_name` | varchar(255) | Required |
| `profile_picture_url` | varchar(500) | Optional |
| `phone` | varchar(20) | Optional |
| `password_changed_at` | timestamptz | Optional; supports token invalidation |
| `is_active` | boolean | Defaults to true |
| `created_at` | timestamptz | Server timestamp |
| `updated_at` | timestamptz | Updated on model changes |

### `visits`

Provider-owned visit records and transcription results.

| Column | Type | Notes |
| --- | --- | --- |
| `id` | UUID | Primary key |
| `user_id` | UUID | Foreign key to `users.id`, indexed |
| `patient_ref` | varchar(255) | Required, indexed |
| `visit_date` | timestamptz | Required, indexed |
| `chief_complaint` | text | Optional |
| `audio_file_path` | varchar(500) | Local path or storage key |
| `audio_duration_seconds` | integer | Optional |
| `transcript` | text | May contain PHI |
| `transcription_status` | varchar(50) | Defaults to `pending`, indexed |
| `transcription_confidence` | float | Optional Deepgram metadata |
| `num_speakers` | integer | Optional Deepgram metadata |
| `transcript_segments` | JSONB | Optional diarized segments |
| `transcription_error` | text | Optional failure detail; must not contain PHI |
| `is_live_transcription` | boolean | Defaults to false |
| `transcription_session_id` | UUID | Optional pointer to a session |
| `created_at` | timestamptz | Server timestamp |
| `updated_at` | timestamptz | Updated on model changes |

### `notes`

Generated SOAP notes and patient summaries.

| Column | Type | Notes |
| --- | --- | --- |
| `id` | UUID | Primary key |
| `visit_id` | UUID | Foreign key to `visits.id`, indexed |
| `content` | JSONB | SOAP sections, metadata, and patient summary; may contain PHI |
| `note_type` | varchar(50) | Defaults to `soap` |
| `status` | varchar(50) | Defaults to `draft`, indexed |
| `synced_sections` | JSONB | Tracks synchronized section state; defaults to `{}` |
| `created_at` | timestamptz | Server timestamp |
| `updated_at` | timestamptz | Updated on model changes |

The note payload evolves independently of the table. Use `backend/app/schemas/note.py` for API validation and `backend/app/services/note_generation.py` for generated-content normalization; do not treat old sample JSON as a schema contract.

### `transcription_sessions`

State and timing for live Deepgram sessions.

| Column | Type | Notes |
| --- | --- | --- |
| `id` | UUID | Primary key |
| `visit_id` | UUID | Foreign key to `visits.id`, indexed |
| `session_status` | varchar(50) | Defaults to `active`, indexed |
| `started_at` | timestamptz | Server timestamp |
| `ended_at` | timestamptz | Optional |
| `total_duration_seconds` | integer | Excludes pauses |
| `pause_count` | integer | Defaults to 0 |
| `websocket_connection_id` | varchar(255) | Optional application connection identifier |
| `created_at` | timestamptz | Server timestamp |
| `updated_at` | timestamptz | Updated on model changes |

### `audit_logs`

Security-relevant event trail.

| Column | Type | Notes |
| --- | --- | --- |
| `id` | UUID | Primary key |
| `user_id` | varchar(36) | Optional, indexed; intentionally not a foreign key |
| `event_type` | varchar(50) | Required, indexed |
| `ip_address` | varchar(45) | Optional |
| `user_agent` | varchar(500) | Optional |
| `detail` | varchar(500) | Optional; must not contain PHI or secrets |
| `created_at` | timestamptz | Server timestamp, indexed |

## Migration workflow

```bash
docker compose exec backend alembic current
docker compose exec backend alembic upgrade head
docker compose exec backend alembic revision --autogenerate -m "description"
```

Review every autogenerated migration before applying it. Never modify a migration that may already have run in another environment; add a new migration instead. Production deployment creates a pre-migration RDS snapshot, but migrations must still be designed to preserve data and support rollback planning.
